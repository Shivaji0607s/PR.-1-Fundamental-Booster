# 📊 Fundamental Booster – Excel Practice Project

## 📌 Project Overview

**Fundamental Booster** is an Excel-based practice project designed to strengthen fundamental spreadsheet skills through practical, real-world datasets. It demonstrates the use of Excel formulas, logical functions, date calculations, conditional analysis, and data extraction techniques.

The workbook contains three datasets covering student academic performance, sales transactions, and employee information. It is suitable for students, beginners, and aspiring data analysts who want to improve their Excel skills.

## 🎯 Project Objectives

- Practice essential Excel formulas and functions.
- Perform calculations on student marks and percentages.
- Analyze sales amounts and discount eligibility.
- Calculate employee ages and date differences.
- Apply logical conditions to classify records.
- Develop a foundation for data analysis and reporting.

## 📂 Workbook Structure

### 1. 🎓 Students_Grade

Contains student information and academic performance data.

**Key columns:**
- Student ID
- Student Name
- Math, Science, and English Marks
- Enrollment Date
- Total Marks
- Total Percentage
- Grades
- Math and Science Performance Status
- Average Score Analysis

**Excel concepts used:**
- `SUM()` and arithmetic calculations
- `IF()` and nested `IF()` statements
- `AND()` for multiple conditions
- `AVERAGEIFS()` for conditional averages
- Percentage calculations
- Grade classification and performance evaluation

### 2. 💰 Sales_Data

Contains sales transaction details for analyzing product sales and discounts.

**Key columns:**
- Sales ID
- Product
- Region
- Salesperson
- Amount
- Date
- Discounts %
- Discount Eligibility
- Rounded Amount
- Ceiling Amount
- Floor Amount

**Excel concepts used:**
- `IF()` for discount classification
- `OR()` for eligibility conditions
- `ROUND()` for rounding values
- `CEILING()` to round amounts upward
- `FLOOR()` to round amounts downward
- Date-based sales records
- Conditional sales analysis

### 3. 👨‍💼 Employee_Data

Contains employee details for basic workforce and date-related analysis.

**Key columns:**
- Employee ID
- Employee Name
- Department
- Salary
- Joining Date
- Date of Birth
- Age
- Difference in Days Between Dates

**Excel concepts used:**
- `DATEDIF()` to calculate age
- `TODAY()` for current-date calculations
- Date difference calculations
- Employee data organization
- Salary and department information management

## 🚀 How to Use

1. Download or clone this repository.
2. Open `PR. 1 Fundamental Booster.xlsx` in Microsoft Excel.
3. Explore the `Students_Grade`, `Sales_Data`, and `Employee_Data` worksheets.
4. Review the formulas used in the calculated columns.
5. Change sample values to practice formulas and observe the results.
6. Add your own datasets to experiment with similar calculations.

After working with this project, users should be able to:

- Apply basic and intermediate Excel functions.
- Use logical functions to evaluate conditions.
- Calculate percentages, grades, ages, and date differences.
